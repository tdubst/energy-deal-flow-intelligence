# Diligence Workflow

Default opportunity workflow:
1. Identify BESS/interconnection signal.
2. Confirm IA date and project maturity.
3. Map POI and nearby transmission.
4. Screen parcels within corridor.
5. Penalize flood/buildability constraints.
6. Import owner/entity data.
7. Estimate screening upside.
8. Generate narrative deal page.
9. Produce report and CSV export.
10. Track diligence until outreach-ready.

Initial statuses:
- Signal Detected
- Screened
- Ownership Verified
- Outreach Ready
- Active Diligence
