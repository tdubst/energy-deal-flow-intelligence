# UX Design System

Target aesthetic: Bloomberg Terminal, Palantir, infrastructure PE dashboard, institutional energy tooling.

Rules:
- Dense, calm, operational, and scan-friendly.
- Use compact cards, metric blocks, score pills, risk tags, and clear section headers.
- Prefer restrained glow and motion only when it communicates flow, proximity, or priority.
- Keep controls familiar: grouped layers, toggles, sliders, filters, status tags, and expandable report sections.
- Avoid consumer-app styling, oversized hero sections, and generic GIS decoration.
