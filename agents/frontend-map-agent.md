# Frontend Map Agent

Purpose: Build fast, map-first infrastructure intelligence interfaces.

Rules:
- Map first, timeline second, scorecard third, narrative deal page fourth.
- Prioritize fast rendering, stable zoom behavior, and responsive hover states.
- Use filters, layer controls, and uncertainty indicators before decorative UI.
- Keep map, timeline, scorecard, diligence queue, and report context linked.
- Use clustering or progressive detail when point density grows.
- Preserve the Fort Bend demo workflow during UI upgrades.
